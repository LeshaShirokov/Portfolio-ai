# Portfolio-ai — портфолио программиста

Адаптивная статическая страница-портфолио Python/Django разработчика на чистых HTML и CSS, без сборки и внешних зависимостей. Публикуется через GitHub Pages.

**Посмотреть:** https://leshashirokov.github.io/Portfolio-ai/

## Что внутри

- главная страница: «Обо мне» с фото, навыки, проекты, опыт, форма заявки и контакты;
- переключатель светлой и тёмной темы (по умолчанию берётся из настроек системы, выбор запоминается в браузере);
- страницы проектов с подробным описанием, на них ведут карточки в разделе «Проекты»;
- форма заявки на разработку с обязательным согласием на обработку персональных данных и страница политики (152-ФЗ);
- адаптивная вёрстка для телефона и компьютера.

## Структура

- `index.html` — главная страница
- `project-1.html`, `project-2.html`, `project-3.html` — страницы проектов
- `privacy.html` — политика обработки персональных данных
- `static/css/style.css` — стили
- `static/img/photo.jpg` — фотография
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

## Запуск локально

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000.

## Статус

- Форма заявки работает в тестовом режиме: данные никуда не отправляются и не сохраняются, после отправки показывается окно об этом.
- Имя, тексты проектов, контакты и ссылки на код и демо — заполнители, их нужно заменить своими.
- В `privacy.html` нужно заполнить выделенные поля (данные оператора, способ приёма заявок) и показать текст юристу.
