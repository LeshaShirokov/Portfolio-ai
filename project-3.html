Проект 3 — Блог / CMS

  • Django
  • HTML/CSS/JS
  • Git

О проекте

Блог с панелью для редакторов: статьи, категории, теги, комментарии и модерация. Важно было сделать удобную админку и аккуратный адаптивный интерфейс.

Что я сделал

  • Разработал модели контента и административную панель
  • Сверстал адаптивный интерфейс без лишних зависимостей
  • Добавил комментарии, модерацию и поиск по статьям
  • Настроил SEO-разметку и карту сайта

Результат

  • Редакторы публикуют материалы без помощи разработчика
  • Страницы хорошо индексируются поисковиками
  • Интерфейс удобен на телефоне и компьютере
